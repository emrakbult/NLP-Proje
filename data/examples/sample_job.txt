İş Başlığı: Backend Veri Platformu Mühendisi
Departman: Veri Ürünleri ve İç Platformlar
Konum: Hibrit

Rol Hakkında
Finans, operasyon ve müşteri başarısı ekiplerinin kullandığı iç veri ürünlerini desteklemek için backend odaklı bir yazılım mühendisi arıyoruz. Mühendis Python servisleri geliştirecek, veri pipeline'larını sürdürecek, REST API'ler sunacak ve raporlama iş akışlarının güvenilirliğini artıracak.

Sorumluluklar
- Python ve FastAPI kullanarak backend servisleri geliştirmek ve bakımını yapmak.
- İç paneller ve operasyonel araçlar için REST API uç noktaları tasarlamak.
- Verimli SQL sorguları yazmak ve PostgreSQL veritabanlarıyla çalışmak.
- Pandas ve üretime hazır ETL pratikleriyle veri işleme iş akışları oluşturmak.
- Diğer mühendislerle iş birliği için Git ve kod inceleme süreçlerini kullanmak.
- Yerel geliştirme ve dağıtım için servisleri Docker ile paketlemek ve çalıştırmak.
- Temel izleme ve konfigürasyon dahil AWS üzerinde servisleri dağıtmak veya desteklemek.
- Agile bir ekipte analistler, ürün yöneticileri ve QA mühendisleriyle koordinasyon sağlamak.
- Veri güvenilirliği, dokümantasyon ve olay inceleme süreçlerini iyileştirmek.

Gerekli Beceriler
- Güçlü Python programlama deneyimi
- SQL ve PostgreSQL deneyimi
- FastAPI veya benzeri frameworklerle REST API geliştirme
- Git tabanlı sürüm kontrolü ve kod inceleme
- Veri analizi veya veri mühendisliği deneyimi
- Konteyner servisler için Docker deneyimi
- Bulut dağıtımı veya servis operasyonu için AWS deneyimi
- Linux komut satırı aşinalığı
- Açık iletişim ve takım çalışması

Tercih Sebebi
- Zamanlanmış veri iş akışları için Apache Airflow
- GitHub Actions veya Jenkins ile CI/CD deneyimi
- Kafka veya olay güdümlü veri işleme
- Kubernetes deneyimi
- Finans, ödeme veya raporlama sistemleriyle çalışma deneyimi

Değerlendirme Odakları
En iyi adaylar güçlü backend ve veri mühendisliği temelleri göstermelidir. Docker, AWS veya Airflow deneyimi eksikse bu beceriler rol için önemli olduğundan mülakatta ele alınmalıdır.
